# Self-Balancing-Robot-thirdspace
## Vertically Self balancing robot project for HackClub YSWS thirdspace, using two motors, an MPU6050 sensor and PID algorithm

Unfortunately I will be sorta abandoning this project after this first week, due to really unfortunate circumstances.
 \
My teammate got really sick and was unable to get time completed this week, so I will have to join a new team for next week.  
The code is basically done, it just needs to be tested on the actual robot and some constant values would need to be adjusted.  
However the physical robot wasn't available (my teammate was supposed to build it) so I ended up using the Wokwi emulator to do some testing.  
The demo of the code also utilizes the emulator, cuz i dont really have any other option.   
I first tried testing the sensor with motors but only stepper motors were available in wokwi, even though the project planned to use dc motors (same as the ones in the LFR), so I tested that a bit but then ended up using leds to represent the forward and backward directions of the motors.
